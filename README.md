# 随打随学输入法

打中文，学英语｜拼音＋五笔输入法

这里是 v18 的私有发布准备仓库。普通用户最终只需下载 `随打随学输入法-v18-Setup.exe`；安装包无需再压缩。

本版面向 Windows 10。Windows 11 尚未完成此安装包的整体验收；Windows 7 不在此安装包的支持范围。

安装与设置见 Release 附件中的《安装说明.txt》，改动见《本版更新说明.txt》。下载后请按《SHA256校验值.txt》核对文件。

公开发布前仍需核实随包开源组件的许可及对应源码获取方式。当前仓库保持私有，Release 保持草稿。
